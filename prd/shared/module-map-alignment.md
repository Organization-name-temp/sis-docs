# Canonical requirements and backend-map references

[Business module index](../README.md) · [Workflow](../workflow.md) · [Backend-map references](backend-map.md)

135 requirements are active; 11 native-mobile/device-push requirements are DEFERRED with no current release. Existing active releases remain assigned; draft map-derived policies need institutional review. IDs remain stable, and every requirement has a matching T-* family. Business module analysis comes first; later derived work uses Phase 1 Backend+AI+UI/UX, Phase 2 Frontend, Phase 3 QA. Security follows each phase and excludes UI/UX assessment.
